# The Intrinsic Review — design prototype

This is a static design prototype of The Intrinsic Review, a UK finance education publication.

- It is not financial advice, and not the production site. The production build is planned as a separate Astro + CMS project.
- `index.html` is self-contained (CSS and JS inlined) and uses hash routing.
- `fonts/` holds self-hosted woff2 subsets. Their OFL licences are in `fonts/licenses/`.
